# assets/cards/ —— 卡册素材

104 张线条小狗的卡池。**只读资源**，`pet/cards.py` 运行时读的就是这里。

```
assets/cards/
├── cards.json        清单：104 条 {id, file, tier}，按档位从高到低排好
└── thumb/            缩略图 160×160，文件名就是卡的 id（c001.png …）
```

## 为什么没有原图

原图是 630×630、104 张共 12 MB，而卡册格子只显示 80px、徽章栏只有 26px。
放原图进来会让仓库和安装包都胖一圈，换不到任何观感。**要原图去素材目录**
（`~/Downloads/线条小狗PNG素材_透明版/`，或者你自己那份）。

真要做"点开看大图"的话再加 `view/` 一档 320px 就够了 —— 别直接放原图。

## 怎么重新生成

```bash
python tools/build_cards.py                    # 用默认路径
python tools/build_cards.py --src <素材目录> --csv <分档表>
```

分档表在 `docs/卡片分档.csv`（107 行 —— 含被剔除的 3 张，理由见
`docs/抽卡参数方案.md` 第八节）。**卡池的档位以它为准**，改档位就改它再重跑。

素材没变时脚本会跳过缩略图（按修改时间比对），所以重跑很快。

## 想换一整套卡池

卡册这一类和宠物贴图一样**有用户覆盖层**：把新的 `cards.json` 和 `thumb/`
丢进 `<数据目录>/cards/`，程序就整体读那一份，不用动程序目录。

- 开发态的数据目录就是项目根（所以直接在项目里改即可）
- 打包后在 `%APPDATA%\DesktopPet\cards\`

**注意是"接管"不是"合并"**：用户目录里只要有一个 `*.png`，内置的那份就整个不读了。
规则和 `pet/paths.py` 里其它素材一致。

## id 怎么来的

`c` + 分档表里的 `idx`（三位，如 `c003`）。**存档里存的就是这个 id**，
所以：

- 改文件名不影响存档（`cards.json` 里那层映射挡住了）
- 但**改 `idx` 会让存档里的卡全部对不上号** —— 加新卡请往后编号，别插队
