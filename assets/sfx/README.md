# assets/sfx/ —— 音效（可选，当前未启用）

现在程序是**完全静音**的：没有音效、没有背景音乐。
这是刻意的 —— 桌宠常驻桌面，出声会打扰写代码和开会。

## 如果以后要加

Qt 用 `QSoundEffect` 或 `QMediaPlayer` 播放。建议：

| 事件 | 文件名建议 | 说明 |
|---|---|---|
| 单击回应 | `poke.wav` | 短促，< 300 ms |
| 落地 | `land.wav` | 配合 `fall` 落地那一刻 |
| 撞碎方块 | `break.wav` | 小游戏里命中 |
| 得分/过关 | `score.wav` / `levelup.wav` | 只在结算时响 |

## 硬性要求

- **格式用 `.wav`**（`QSoundEffect` 对 wav 支持最稳，mp3 在部分 Windows 环境会失败）
- 时长控制在 1 秒内，体积小了打包也轻
- **一定要在右键菜单里给一个「静音」开关**，默认静音 —— 否则这个功能会毁掉桌宠的存在感
